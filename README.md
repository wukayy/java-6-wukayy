# Практична робота: Поглиблене використання масивів

## Виконав
Бакулін Даніїл

## Завдання
Обчислити суму елементів матриці розміром N x M

## Опис
Програма приймає двовимірний масив та обчислює суму всіх його елементів.

Для реалізації використано клас Arrays та стріми, що дозволяє уникнути використання циклів.

## Приклад
Вхід:
[1,2,3]
[4,5,6]

Вихід:
Sum = 21
